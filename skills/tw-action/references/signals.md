# 訊號庫：執行阻滯的六種訊號

識別出訊號後讀取對應條目。每條包含：表現、機制、鑑別要點、解法、可用的一句話。

「可用的一句話」裡凡是「你不是在 X，你是在 Y」的句式，都附有使用條件：只有使用者自己說過 X，才可以這樣說；否則改用條目裡的直述版本。

---

## 訊號 A：執行模擬器

**表現**：把身邊的人和工具都當成「模擬器」，用別人的預判代替執行。

- 「你覺得這個方案怎麼樣？」：你成了他的方案模擬器；
- 「如果我把這段發給 AI 會怎樣？」：你成了他的 AI 模擬器；
- 「你幫我看看這個能不能做」：你成了他的市場調研模擬器；
- 發一篇文章給你，問「你看完感受怎麼樣」：你成了他的閱讀模擬器。

**機制**：承受不了任何微小的失敗風險，所以每件事都要先在別人的腦子裡跑一遍。模擬的結果不會失敗，也不會產生真實反饋。dontbesilent 的觀察：模擬很多次，真正執行的極少。

**鑑別**：

- 問過一次、拿到意見後就去做了，屬於正常諮詢；
- 同一件事反覆問不同的人，問完不動，才是執行模擬器；
- 問題本身需要專業判斷（法律、醫療、資金安全），先諮詢是合理的。

**解法**：

1. 列出最近反覆問別人的那件事，找到它最小的可執行版本；
2. 把這個版本直接放進真實場景：發出去、報價、上架、發給真實的人；
3. 規定反饋來源只能是現實：使用者的反應、成交、平台資料；
4. 下次想問「你覺得行不行」時，先問自己：這個問題現實能不能直接回答？能，就去做。

**可用的一句話**：

- 直述：「你在用別人的預判代替現實的反饋，而只有現實能告訴你行不行。」
- 條件句式：使用者說過「我在做準備 / 我在調研」時，可以說「你不是在準備執行，你是在用準備代替執行」。

## 訊號 B：用思考替代行動

**表現**：反覆思考、分析、計劃，從不開始。

- 「我再想想」
- 「我先把方案想清楚」
- 「等我準備好了就開始」
- 規劃、覆盤、梳理、討論、總結佔滿了時間，產出很少。

**機制**：思考本身帶來「事情在推進」的感受，於是成了終點，而不是行動的前序。準備可以無限重啟、反覆享受。dontbesilent 把規劃、覆盤這類活動的一部分稱為「給自己做心理按摩」：感受變好，事情沒動。

dontbesilent 還認為，「過度思考導致沒執行力」這個說法，是對不願執行的美化。執行意味著可能失敗，還意味著失敗後要面對結果；思考是繞開這兩個風險的方式。另一個依據是：不行動就沒法想清楚，很多問題只有做完才知道是什麼。

**鑑別**：dontbesilent 區分了兩種人。缺執行力的人，思緒亂時要停止思考、先動起來（stop thinking）；不缺執行力的人，思緒亂時要停下動作、先想清楚（stop doing）。使用者近期大量行動、只是方向混亂時，不歸入訊號 B。

**解法**：

1. 給思考設截止點：今天之內必須結束規劃，寫下當前最好的版本；
2. 找一個做完就能產生新資訊的小動作，資訊來自現實，不來自腦內推演；
3. 想不清的問題記下來，標註「行動後再想」；
4. 時間管理只抓一件事：每天優先做最重要的一件，其餘都可以拖延甚至放棄。

**可用的一句話**：

- 直述：「這件事你想不清楚，是因為還沒做；做了才有新的資訊可想。」
- 條件句式：使用者自稱「我就是想太多 / 過度思考」時，可以說「你不是在過度思考，你是在用思考迴避行動」。

## 訊號 C：方向跳躍

**表現**：頻繁更換方向，每個方向都做不久。

- 「這個不太適合我，換一個」
- 「我又發現了一個更好的方向」
- 「上一個太難了，這個簡單一點」

**機制**：每次在要深入時撤退。深入意味著可能被證明失敗；不斷換方向，失敗就永遠停在「還沒驗證」的狀態。dontbesilent 的失敗觀：失敗越快，成功越快，做事應該儘快拿到負反饋。方向跳躍恰好躲開了負反饋。

**鑑別**：

- 換方向前有明確的負反饋證據（資料、成交、使用者反應），屬於正常迭代；
- 換方向的理由只有「感覺不適合」「新的更好」，且每次都在差不多的階段放棄，才是訊號 C；
- 使用者一直在一個方向上埋頭做、從不看資料，屬於另一種問題：固執，不在此列。

**解法**：

1. 選一個方向，先寫下「做到什麼程度才允許換」，例如發滿約定數量的內容，或拿到第一筆收入；
2. 到達這個標準之前，新方向只記錄，不啟動；
3. 真要換時，先寫下上一個方向的負反饋證據，證據不足就繼續；
4. 把每次放棄的階段列出來，看是否總在同一種難點前撤退，那個難點才是要處理的問題。

**可用的一句話**：

- 直述：「你每次都在同一個位置撤退，換的是方向，躲的是同一件事。」
- 條件句式：使用者說過「我還在找方向」時，可以說「你不是在找方向，你是在逃避深入」。

## 訊號 D：知識上癮

**表現**：不停學習、看課、買書、聽播客，但不開始做。

- 「我覺得我還需要學更多」
- 「等我把這個課學完就開始」
- 「我先看看別人怎麼做的」

**機制**：學習成了不執行的合法理由。dontbesilent 的判斷：很多所謂學習，是不想幹又不願意承認，所以假裝在努力。極度的不自信加上殘留的幻想，結果就是一直學下去。購買知識時，買到的常常是「我正在進步」的感受。

**鑑別**：

- 正在做，因為碰到具體問題去學，屬於正常學習；
- 學習內容和要做的事沒有直接關係，或學完一門又開一門、始終沒有產出，才是訊號 D；
- 使用者缺的是一項必須先掌握的硬技能（例如必須持證上崗），先學是合理的。

**解法**：

1. 停止新增輸入：暫停購買新課、新書；
2. 用已有知識交付一個結果，哪怕粗糙；
3. 之後只為執行中碰到的具體問題去學，學完立刻用；
4. 例如鏡頭恐懼，dontbesilent 的說法是拍夠足夠多條之後就沒有了，靠拍解決，不靠學解決。

**可用的一句話**：

- 直述：「你買到的是『正在努力』的感受，事情本身沒有往前走。」

## 訊號 E：完美主義

**表現**：因為做不到完美而不開始、不發布。

- 「我的產品還不夠好」
- 「等我再打磨一下」
- 「我不想做出一個平庸的東西」

**機制**：完美主義常常是自卑的高階偽裝。它讓人可以說「我做不好，是因為我對自己要求高」，用高標準合理化不行動。高標準的作用是推遲被評價的時刻。

**鑑別**：

- 已經在持續交付，只是在某個環節反覆打磨，可能是正常的品質要求；
- 從未交付過，或交付物長期停在「快好了」，才是訊號 E；
- 行業有硬性標準（安全、合規、醫療），未達標不發布是必要的。

**解法**：

1. 把發布門檻降到「能讓一個真實的人用起來」；
2. 先給小範圍的人看：幾個朋友、一個群、一個小號；
3. 把評價當資訊收集：只記錄反饋裡能用來改進的具體內容；
4. 課題分離：別人怎麼評價是別人的課題，按時交付是自己的課題。

**可用的一句話**：

- 直述：「完美主義讓你推遲被評價的時刻，產品沒有因此變好。」
- 條件句式：使用者說過「我只是對自己要求高 / 標準高」時，可以說「這不是標準高，是害怕被評價」。

## 訊號 F：歸咎外部

**進入條件**：只有透過真實困難判斷（見 `safety-screening.md`）之後才使用本條。使用者提到的限制真實存在、且確實排除了所有可行版本時，不進入訊號 F。

**表現**：把不行動歸咎於外部。

- 「家人不支援我」
- 「我現在的工作太忙了」
- 「沒有啟動資金」

**機制**：阿德勒視角下，很多「被迫」其實是自願選擇後歸咎於外部。dontbesilent 的說法是：對方手裡沒有槍，就很難真正強迫你。把選擇敘述成被迫，可以免除選擇的責任。

**鑑別**（判斷後仍需注意）：

- 限制只排除了使用者心裡那一個版本（例如「辭職全職做」），沒有排除更小的版本（例如下班後做），而使用者放棄了全部版本，才是訊號 F；
- 使用者說「工作太忙」，但每天有可觀的時間花在刷手機、看課等替代行為上，可以作為依據；
- 家人反對涉及共同財產、共同債務、照護分工時，反對本身就是需要協商的真實約束，不只是別人的課題。

**解法**：

1. 把使用者列出的理由逐條分成兩類：客觀約束、可以選擇的理由；
2. 課題分離：家人支不支援是家人的課題；在不違背共同承諾的前提下做不做，是自己的課題；
3. 在約束內找一個可做的版本：更小規模、更低成本、利用現有時間；
4. 直接說出選擇：「在目前條件下，我選擇暫時不做」也是一個誠實的結論，比「我被困住了」更能讓人重新做決定。

**可用的一句話**：

- 直述：「這些限制排除了你心裡的那種做法，沒有排除所有做法；剩下的那些你還沒試。」
- 條件句式：僅在困難判斷確認沒有真實約束、且使用者說過「我被困住了」時，可以說「你不是被困住了，你是選擇了留在原地」。語氣保持冷靜，不帶嘲諷。

## 補充：價值感低、依賴外部正反饋

不單列為訊號，可以疊加在任何訊號上。表現為：做事完全靠別人誇獎驅動，一次沒反饋就停；遇到逆境時找不到自己的動力。

**解法**（阿德勒：共同體感覺）：

1. 找一個需要幫助的具體的人；
2. 用自己已有的知識，幫他解決一個具體的小問題；
3. 從他的反應裡拿到「我對別人有用」的證據；
4. dontbesilent 的經驗：先做能快速拿到正反饋的事情，比如先拿到一筆短期收入，再用這份底氣推進難的事。
