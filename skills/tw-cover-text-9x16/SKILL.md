# tw-cover-text-9x16：直式封面字

使用者 新增（非上游）。先讀 `shared/USER-PROFILE.md`。

- 1080x1920：主標放中央 1080x1080 安全區（IG 九宮格裁切成 3:4／1:1 仍看得到），上下各留 250px 給平台介面。
- 主標 ≤ 12 字、副標 ≤ 16 字；最多兩行。集數標記「EP.NN」固定在左上角安全區內，需向 主控 bot 確認集數。
- 封面字要兌現影片內容，不誇大；數字要有 facts.md 出處。
- 背景不能有人臉、品牌標誌。
- 交 3 組候選：資訊型、反差型、問題型，各附一句理由。

## 爆紅檢查（依 research/viral-patterns.md）

封面字優先：具體數字（P2）、結果畫面（P5）、搜尋句（P6）。懸念型封面只在影片前 3 秒就兌現時使用。

發布前用 `research/viral-patterns.md` 末段「打分檢查」七題打分（每題 0–2，10 分以上再送查核角色）。每個模式的證據連結與數字都在該檔，引用時不得改動數字。
