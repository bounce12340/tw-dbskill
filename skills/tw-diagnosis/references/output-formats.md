# 輸出格式

欄位沒有內容時整段省略，不寫「無」「待補充」湊格式。

## 體檢：完整報告

使用者要求完整診斷報告、或材料足夠做全部七項時使用。

```markdown
# 商業模式診斷報告

## 基本資訊
- 業務：{描述}
- 產品：{具體產品}
- 價格：{價格體系}
- 賣給誰：{買家}
- 獲客與交付：{平台與方式}
- 月收入：{當前收入；使用者沒給時寫「未提供」並在下方假設中說明}
- 我的假設：{根據材料推斷、尚未確認的事實；沒有則省略}

## 七項檢查
| 檢查 | 結論 | 依據 |
| --- | --- | --- |
| 印鈔機 | {透過 / 不透過 / 部分透過 / 依據不足} | {一兩句} |
| 道德 | {好模式 / 壞模式 / 灰色地帶} | {一兩句} |
| 定價 | {合理 / 需要調整} | {一兩句} |
| 需求 | {真實需求是什麼} | {一兩句} |
| 流量與變現 | {結構合理 / 需要調整} | {一兩句} |
| 規模化 | {可規模化 / 還沒到時候 / 不可規模化} | {一兩句} |
| 成長層級 | 第 {N} 層 | {當前層的核心任務} |

## 成熟度訊號
{定價、付費客戶、復購、對標：只寫缺失的項和它的含義}

## 替代方案
{如果換一個商業模式：一到兩個具體替代，以及它比現在好在哪、代價是什麼}

## 核心判斷
{一段話：這門生意的本質、最大的問題、最優先要解決的}

## 一句話處方
{犀利、直接，像 dontbesilent 發推文}

## 明天你要做的第一件事
{一個具體動作}
```

## 體檢：簡化形態

材料只夠判斷少數幾項，或使用者只要結論時使用：

```markdown
**核心判斷**：{一段話}

**最大的問題**：{對應哪一項檢查，依據是什麼}

**依據不足的項**：{哪些檢查缺什麼事實；不影響核心判斷時省略}

**明天你要做的第一件事**：{一個具體動作}
```

## 問診：預設形態

```markdown
**你問的是**：{一句話複述}

**判斷**：{問題在哪一層被消解，或真問題的答案；條件判斷寫成「如果 A，就 X；如果 B，就 Y」}

**為什麼**：{兩三句依據}

**替代思路**：{僅在給出業務方案時寫}

**明天你要做的第一件事**：{一個具體動作}
```

簡單問題（資訊類、被語言陷阱一句話消解的問題）只寫判斷和一句依據。
