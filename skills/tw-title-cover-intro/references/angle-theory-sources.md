# 12 視角的理論依據與使用邊界

本檔案說明角度開發所用理論的來源和遷移限制。理論只幫助提出可檢查的內容命題；理論名稱、研究結論和未經核實的因果不能自動寫進面向觀眾的標題、封面或口播。12 個視角的判斷動作與分組見 [深挖：12 視角分 3 組](angle-development.md)。

「已核對原文」表示該來源的可訪問原文或出版社節選已進入本專案的資料核對；「已有資料記錄」表示記錄了書目和理論邊界，具體版本或頁碼仍需在對外引用時重新核對；JTBD 在這裡作為操作框架使用，不主張單一學術首創者。

| 視角 | 來源與核對狀態 | 遷移到內容角度時的限制 |
| --- | --- | --- |
| L01 社會學想象力 | C. Wright Mills，*The Sociological Imagination*，1959；[出版社收錄的原文節選](https://cmn-cdn-001.sagepub.com/books/titles/283045/att_sb1_130400.pdf)，已核對原文。 | 個人困擾可引出對公共問題的調查；單個故事不證明結構性原因或群體分佈。 |
| L02 抽象階梯 | S. I. Hayakawa，*Language in Action*，1939，及後續 *Language in Thought and Action*；已有資料記錄，指定版本未逐頁複核。 | 從具體觀察升到原則時，逐級保留事實、機制和成立條件；抽象程度不等於證據強度。 |
| L03 框架理論 | Robert M. Entman，*Framing: Toward Clarification of a Fractured Paradigm*，1993；[論文原文副本](https://fbaum.unc.edu/teaching/articles/J-Communication-1993-Entman.pdf)，已核對原文。 | 問題定義、原因解釋、評價和處理建議可以改變；重新定義不證明新原因真實。 |
| L04 爭點理論 | 西塞羅，*De Inventione*；昆體良，*Institutio Oratoria*，第三卷；已有資料記錄，古典原文未逐頁複核。 | 事實、定義、價值、行動是定位分歧的操作分類，分類本身不證明任何答案正確。 |
| L05 修辭情境 | Lloyd F. Bitzer，*The Rhetorical Situation*，1968；[論文原文副本](https://wac.gmu.edu/wp-content/uploads/bitzer.pdf)，已核對原文。 | 迫切問題、可受表達影響的受眾和現實約束須同時檢查；不能憑空製造時機。 |
| L06 自我參照效應 | Rogers、Kuiper、Kirker，*Self-reference and the Encoding of Personal Information*，1977；已有資料記錄。 | 受眾能把資訊聯絡到自己，不自動意味著會點選、分享或購買。 |
| L07 社會認同與自我分類 | Tajfel、Turner，1979；Turner 等，1987；已有資料記錄。 | 只有真實存在的角色、規範或利益才能形成身份角度，不憑刻板印象劃分群體。 |
| L08 使用與滿足 | Katz、Blumler、Gurevitch，*Uses and Gratifications Research*，1973；已有資料記錄。 | 觀眾可能如何使用內容是待核的任務假設，不能代替受眾行為證據。 |
| L09 JTBD | 用於描述具體情境、行動主體、受阻狀態與期望進展的操作框架；不作單一學者首創歸屬。 | 無當事人原話或行為時，只能提出進展任務假設；購買任務僅在材料涉及購買時分析。 |
| L10 情緒評價理論 | Lazarus，*Emotion and Adaptation*，1991；Smith 與 Ellsworth，*Patterns of Cognitive Appraisal in Emotion*，1985；已有資料記錄。 | 目標相關性、責任、確定性和控制感可幫助提出條件性解釋，不能診斷真實心理。 |
| L11 認知失調 | Leon Festinger，*A Theory of Cognitive Dissonance*，1957；已有資料記錄。 | 需要可指出的舊信念／行為與相矛盾的材料；「反常識」句式不構成證據。 |
| L12 沉默的螺旋 | Elisabeth Noelle-Neumann，1974 年相關研究；已有資料記錄，原文版本待核。 | 需要意見氣候、孤立擔憂或表達成本的材料；「沒人說」不證明「不敢說」。 |

理論來源和邊界不會自動帶來流量結果。新聞價值、資訊缺口等方法可在命題選定後檢查入口和表達，不擔任首輪升層成員，也不能代替正文兌現檢查。
