# 標題、封面與開頭的寫作規則

在方向固定、準備書寫任何文字標題、封面標題、新口播或正文修改建議時讀取。快捷路徑也需要執行。這裡負責把既定意思寫清楚，不重新開發角度。寫後按本檔案檢查，再交付。

## 適用範圍

本檔案採用清晰表達原則檢查主體、動作、物件、指代和語義，並要求措辭自然、具體，保護使用者已經確認的文字。中文屬於本機適配，不宣稱透過 ASD-STE100 正式符合性檢查，不把英文詞數規則換成中文字數。

標題和短影音仍可使用具體懸念、反問、修辭強調與作者強句，前提是讀者知道在談什麼，正文能兌現。

## 先說清楚，再壓縮

1. 用正常中文寫出這份內容要表達的完整意思，明確涉及誰、哪件事、什麼判斷。
2. 從完整意思中選擇當前表面需要的資訊，再縮短文字；不要直接拼出幾行短詞。
3. 保留讓陌生人識別主題所需的主體、物件和關係。短句可以省略已在同一表面明確交代的成分；不能靠未顯示的正文補齊。
4. 先確定自然語句，再分行。每行無需獨立成句，但整個封面必須獨立可懂。
5. 優先順序為：核心含義和獨立理解 → 自然措辭 → 具體吸引力與資訊分工 → 預設行數和字數。平台硬限制與使用者指定的版式必須遵守；無法容納時改用更簡單而完整的命題，或明確版式衝突，不刪除必要物件來硬塞。

## 陌生人單獨看懂

檢查時只保留當前成品，暫時遮住原稿、聊天背景、解釋段落和另一種標題。

- 文字標題獨立顯示時，讀者能否知道主要物件或主題，以及這句話提出的判斷或問題？
- 圖文封面整體獨立顯示時，讀者能否說清它在談什麼？「他」「這個」「差一截」「只回一句」若必須回原稿尋找物件，先補主體或直接改寫。
- 封面去掉換行、連成一句讀時，誰是什麼樣的人、誰做了什麼，是否和原意一致？作者的經歷和對別人的判斷放在同一張封面上時，最容易把兩個主語讀成一個人，詳見 [封面標題](cover-title.md)「連起來讀一遍」；
- IG Reels／TikTok主頁封面能否明確標示這條影片討論的具體主題，並與其他影片區分？「你漏了什麼」這類空泛問句不能完成索引。
- 新口播能否讓沒看標題的人聽懂主語、事件和繼續聽的理由？

懸念可以保留原因、過程或答案；主題和基本關係需要先交代。不能把缺少背景誤當成懸念。

標題與封面可以重複必要的主體、主題詞和關鍵名詞。先保證各自可懂，再避免整句和全部資訊重複。互補不能透過刪除語境實現。

## 用目標觀眾的日常說法

陌生人能看懂主題之後，再檢查：目標觀眾平時會不會這麼說話。

- 標題、封面和口播避免使用平台運營、營銷和學術的行話，除非作者原文這樣說，並且目標觀眾本身就是同行。例如「訂閱邏輯」「分發」「推流」「爭點選」「轉化」「心智」。改成觀眾能直接感受到的事：「關注了也刷不到」「發了沒人看」「沒人點開」。
- 作者原文用了行話、並且這條內容就是講給同行聽的，可以保留原詞；面向更廣的人群時換成日常說法。
- 檢查方法：想象一個不做自媒體的朋友在刷手機時看到這句話，他能不能不停頓就讀懂。

## 給使用者的說明也用大白話

推薦理由、正文建議、選題選單、方向說明和提問都會被使用者閱讀。寫這些文字時，按下面的規則檢查。

**每句話說清誰、做什麼、對什麼。**

- 一句話只說一個判斷。「人多，很在意；稿子後半段撐得住」這類把幾個判斷擠在一起的寫法，拆成幾行，每行寫一件事；
- 寫出動作和物件。「補一個背書會強很多」改成「補充你做了幾年、見過多少人，標題和開頭可以寫進去，觀眾更容易相信」；
- 「它」「這個」「這一層」有多個可能物件時，直接寫名稱。

**不用比喻和內部說法。** Skill 內部的思考用語不出現在使用者可見文字裡。常見替換：

| 內部說法 | 發給使用者時寫成 |
| --- | --- |
| 往上拉、拉幾層、更好拉 | 講給更多人、擴大選題 |
| 底子 | 這份稿子主要講什麼 |
| 拉法、掛母題、換說法 | 直接寫改了哪個詞、加了什麼資訊 |
| 撐得住、撐不撐得住 | 稿子能講清楚嗎、還要補什麼 |
| 錨點 | 稿子裡最吸引人的具體細節，並直接寫出是哪個細節 |
| 背書 | 能讓觀眾相信你的經歷或數字 |
| 回落 | 講完大問題後，回到稿子原來的內容 |
| 層、層級 | 第幾個選題 |

另外不使用：點選型、留存型、注意力推薦、兌現推薦、雙重推薦、入口基準、爭點、證據邊界、抽象層級、四格、F1、L01 和理論名稱。

**按事實說，不加評價包裝。**

- 推薦理由一句，20 字以內，說觀眾為什麼會點或為什麼能看下去，例如「一組數字對比，反差直接」；
- 不解釋流程本身，例如「經過內容價值驗收」「按兩種標準比較」。使用者問「為什麼」時再解釋；
- 判斷人群寫具體人群，不寫「所有人」「大眾」；人數多少和關不關心分開寫。

交付前把給使用者的每一行讀一遍：不知道這個 Skill 內部規則的人，能不能直接看懂？看不懂就改。

## 動詞要符合日常說法

檢查動詞與物件的搭配，以及整個句子是否像人在這個場景下會說的話。使用材料中已有的具體動作；不能為了顯得短、有力或有方法，臨時創造抽象搭配。

尤其避免「你漏了什麼」這類把複雜判斷壓成單一動詞、再省略物件的寫法。不要只把「漏」換成「遺漏」「補齊」繼續保留模糊句式；重新寫出具體意思，例如當前內容到底在問是否考慮了獲客方式、交付能力，還是在討論某種創業行為。成品不必全部寫進，但必須能判斷具體主題。

按語境檢查，不機械封禁所有單字動詞。原作者明確使用、物件清楚且自然的表達應保留；「漏寫一個字」這樣的實際動作與空泛鉤子分開處理。解釋句、推薦理由和改稿建議同樣遵守自然措辭要求。

同一物件使用同一名稱，準確詞語可以重複。避免為換說法增加抽象名詞；避免「不是……而是……」及專案禁止的近似句式。引用原文或使用者明確要求時遵守原文保護規則。

## 保留力度和原意

- 保留選定方向、原稿強句、事實、條件、否定、因果與承諾強度。清晰表達不能擅自更換立場，也不能把所有觀點改成操作說明。
- 對不影響核心理解的概括、強調和次要條件省略，按主 Skill 的表達尺度保留；不用層層限定抵消作者力度。
- 為補全語境，只能使用材料已有的資訊；不能編造數字、人物行為、受眾心理或效果。
- 原話素材不靜默改寫。新寫口播與已拍原話分開，使用者鎖定文字優先於預設規則。

## 交付前實際檢查

對每個成品分別完成：遮住上下文 → 複述主題和判斷 → 檢查動作與指代 → 正常讀一遍 → 對照原意 → 核對長度和換行。

複述時只能使用當前成品中已有或可直接理解的資訊，不能偷偷呼叫原稿替它解釋。若需要附一段說明才能證明這句封面「其實講得通」，先改成品。字元數合格不能代替理解檢查。

同一處理解或用詞問題反覆出現時，修正寫法並保留使用者否定過的結果作為迴歸樣本；不能只在分析裡承認問題，繼續把它放進推薦。檢查在內部完成，使用者未要求時不附逐項評分表或寫作規則講解。
