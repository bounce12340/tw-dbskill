# 快速角度掃描

[流量層級梯子](topic-ladder.md) 的輔助工具：梯子找不到下一層、需要換角度看同一件事，或使用者要求換個方向時使用。由主 Agent 自己完成，不開子 Agent。第 0 步已併入梯子第 1 步，從梯子進入時可以跳過。事實與表達檢查遵循主 Skill 的表達尺度；本檔案只在內部產生角度候選，不單獨設定確認關口，也不把掃描過程展示給使用者。

## 0．先看整篇許諾了什麼

拆材料之前，先回答：讀者看完整篇能拿走什麼。常見幾種：

- **一套方法**：多條做法合起來解決一個問題，例如「我如何三個月學會剪輯」；
- **一份清單或合集**：幾條並列的經驗、工具、案例；
- **一個判斷**：作者要證明一個觀點；
- **一個故事或一次經歷**：有過程、有結果；
- **一種體驗**：好笑、好看、共情。

整篇許諾本身就是首要候選方向，經常也是原稿能火的原因。一套方法或一份清單類的內容，「有這套方法／有這份清單」就是方向；按摩店、咖啡這類具體技巧是這套方法的證據和鉤子，放進標題、封面或開頭裡用，不單獨拆成方向。只有某個部分明顯比整體更強、並且正文能單獨撐起時，才把它升為獨立方向。

原稿已有標題時，原標題對應的方向必須進入候選，並進入方向選單；內部比較認為它更弱時，也要在選單裡保留，由使用者決定。

## 1．恢復輸入核心

一句輸入核心同時保留：發生了什麼、使用者準備解釋什麼、哪些事實負責製造注意力。壓縮後如果只剩「AI」「商業」「成長」「賺錢」等寬泛概念，重新恢復具體事件、數字、行為和條件。

## 2．相關性掃描

生成 2～5 個真正不同的候選。每個候選寫清：

```markdown
候選方向：
不可丟失的輸入資產：
注意力理由：
有效受眾：
具體處境：
共同後果／受眾問題：
連線機制：
繼續瞭解的價值：
受眾範圍：專業小眾／跨群體／廣泛共同處境
關切強度：弱／中／強
現實訊號：已確認／有線索／未確認
證據狀態：已確認／有依據的推斷／待驗證
```

每個候選都應能寫成一句話：這份材料透過什麼機制，在什麼場景下，影響了哪類人的什麼後果、選擇或任務；他們看完能多理解、多判斷或多做什麼。寫不出這句話的候選，只是關鍵詞或情緒相近，不進入比較。

注意力理由與繼續瞭解的價值分開判斷。數字很大、人物知名或事件獵奇，只能證明受眾可能先看一眼；還需要正文提供理解、判斷、行動價值，或故事進展、幽默、情緒與審美體驗，才能形成持續連線。

受眾範圍和關切強度分別判斷。專業小眾可以擁有強關切，廣泛人群也可能只有概念聯絡。不要把行業詞替換成「賺錢、成長、焦慮」後直接判為大眾相關。

現實訊號單獨判斷：邏輯上和很多人有關，只說明可能覆蓋的人多；現在是否真有很多人在討論、搜尋或諮詢，需要材料裡的評論、提問、諮詢、資料，或使用者提供的平台反饋。沒有這類訊號時記為「未確認」，不能把「理論上人多」說成流量大。

## 3．爭點掃描

輸入包含已經發生的事件、衝突、公開回應或可評價行為時，掃描：

| 型別 | 核心問題 |
| --- | --- |
| 事實爭點 | 到底發生了什麼？原因是否成立？ |
| 定義爭點 | 這件事應當被理解成什麼？ |
| 價值爭點 | 它是否合理、重要、可責或可原諒？ |
| 行動爭點 | 誰應該怎麼回應、選擇或改變？ |

每個有效爭點包含：

```markdown
爭點問題：
立場 A：
立場 B：
觀眾為什麼在意：
使用者獨有的位置：
已有證據：
缺失證據：
```

雙方沒有真實判斷差異時，爭點不成立。方法型、教程型和普通經驗沒有合格爭點時，可以跳過，不得為了評論量製造對立。

## 4．選擇抽象路徑

分別檢查 4 種變化：

```text
抽象：具體事實 → 重複模式 → 解釋機制 → 條件性原則
人群：個人 → 同角色群體 → 跨群體 → 公共問題
時間：一次事件 → 重複處境 → 長期結果
價值：事物屬性 → 使用後果 → 決策標準 → 價值衝突
```

標題通常需要一組「入口＋終點」：

- 入口使用低抽象的具體人物、行為、數字或異常事件；
- 終點說明受眾點開後將得到的解釋、判斷或行動價值。

不能從單個案例直接跳到普遍原則、時代趨勢或長期因果。抽象層提高時，同步提高證明責任。

## 5．用 12 視角清單補漏

前 4 步完成後，用下面三組問題各過一遍，只找前面漏掉的新受眾或新命題。不逐視角寫結論，沒有新發現就跳過，不開子 Agent。

- **結構與抽象**（L01、L02、L03、L12）：個人經驗背後有沒有平台、組織或資源規則？同一事實能不能換一種問題定義，並改變受眾的選擇？能上升到哪一層而不丟具體素材？有沒有因為表達代價而不說話的人？
- **爭點與判斷**（L04、L05、L11）：原文裡有沒有兩種都站得住的判斷，包括作者前後文之間的張力？誰此刻正要做相關選擇？有沒有可指出的舊判斷被材料推翻？
- **受眾與需要**（L06、L07、L08、L09、L10）：原領域之外誰能聯絡到自己的處境？觀眾能拿這條內容判斷什麼、嘗試什麼？誰想推進什麼進展卻卡住了？涉及哪些身份或情緒代價？

補出的候選同樣經過下一步的硬門檻。各視角的邊界見 [深挖：12 視角分 3 組](angle-development.md)。

## 6．硬門檻

先淘汰以下候選：

- 刪除關鍵條件後才顯得普遍；
- 只有關鍵詞、情緒、身份標籤或宏大價值；
- 只有獵奇注意，正文也沒有可繼續觀看的過程或體驗；
- 只有廣泛相關，沒有保留獨家事實；
- 依賴未知動機、未經證實的因果或虛構公眾反應；
- 超過材料的證據上限。

## 7．按「人多不多 × 在不在意」排序

透過門檻的候選先放進四格：

| | 在意（關切中或強） | 不太在意（關切弱） |
| --- | --- | --- |
| **人多**（跨群體或廣泛） | 優先，再看現實訊號和材料能否撐住 | 容易大而空，收窄到更具體的人群，收不窄就淘汰 |
| **人少**（專業小眾） | 保留，作為垂直方向 | 降為素材或淘汰 |

同一格內依次比較：關切強度 → 受眾範圍 → 現實訊號 → 看完能多得到什麼 → 材料是否撐得住。不把這些合成一個總分；事實忠實、作者原意和材料上限是淘汰條件，人再多也不能抵消。

## 8．候選怎麼配（不直接發給使用者）

選單最多 3 個方向，按下面的順序填：

1. **整篇許諾方向**（第 0 步），原稿有標題時通常就是原標題方向；兩者不同時都進選單；
2. 剩下的位置再從以下幾種裡選，用來提供真正不同的講法：
   - **人多又在意**的新人群或新問題；
   - **人少但很在意**、某個具體人群會對號入座的方向；
   - **從作者的成果或親歷切入**：材料裡有作者自己的成績、一手觀察或異常數字時考慮。

所有進入選單的方向都要先透過第 7 步四格：「人少也不太在意」的方向，包括作者親歷方向，不進選單。不同方向必須改變講給誰聽或講什麼問題，只換一個技巧當入口不算新方向。沒有合格的補充方向時，選單隻給 1～2 個也可以，不湊數。

透過門檻後保留 2～5 個真正不同的候選，不預先按單一偏好刪掉方向。交給 [材料選擇](material-selection.md) 與 [候選比較](candidate-selection.md) 共同驗收、篩選，再交回梯子，作為新的一層或放進「其他方向」。只有一個有效候選時如實返回；無合格方向時說明缺少的最小材料。
