# 深挖：12 視角分 3 組

僅在主 Skill 進入深挖時讀取：使用者要求多找方向、深挖或明確點名 12 視角，或快速掃描找不到合格方向。預設流程不讀取本檔案；快速掃描使用 [快速角度掃描](angle-discovery-fast.md) 裡的 12 視角清單補漏。

任務是發現與更多人有真實關係的上層命題，再交給內容價值驗收、製作狀態和正文兌現檢查。不讓成員寫標題。擴大受眾只能產生候選，觀眾是否願意進入和繼續看仍須單獨判斷。

## 為什麼分 3 組

12 個視角各開一個子 Agent 時，多個視角常常匯到同一個方向，成本約為快速掃描的 12 倍，增量有限。把判斷動作相近的視角放進同一組，每組一個子 Agent，組內依次完成各視角，再合併重複路徑。組與組之間仍然獨立，避免互相影響。

## 3 個組

| 組 | 包含視角 | 這一組在找什麼 |
| --- | --- | --- |
| A 結構與抽象 | L01 社會學想象力、L02 抽象階梯、L03 框架理論、L12 沉默的螺旋 | 個人經驗背後的規則和機制；同一事實的另一種問題定義；可以上升到哪一層 |
| B 爭點與判斷 | L04 爭點理論、L05 修辭情境、L11 認知失調 | 真實存在的兩種判斷；此刻正要做選擇的人；舊判斷和新經驗的衝突 |
| C 受眾與需要 | L06 自我參照效應、L07 社會認同與自我分類、L08 使用與滿足、L09 JTBD、L10 情緒評價理論 | 原領域之外的人怎樣聯絡到自己；他們拿內容做什麼、想推進什麼、會有什麼感受 |

## 12 個視角的判斷動作

來源、核實層級與適用邊界見 [角度理論依據](angle-theory-sources.md)。以下判斷動作服務素材開發，不證明播放量、轉發量或成交效果。

| 編號與視角 | 獨立判斷動作 | 必須守住的邊界 |
| --- | --- | --- |
| L01 社會學想象力 | 檢查個人困境是否還與機會結構、組織規則或資源獲得方式有關，提出可調查的共同問題。 | 單個故事或共同情緒不能證明結構性不平等；缺群體資料時只保留問題假設。 |
| L02 抽象階梯 | 從具體事件上移到重複模式、解釋機制、帶條件的共同難題；逐層說清新受眾承擔什麼後果。 | 單個案例不證明普遍規律；刪去具體素材只剩人生道理時退回。 |
| L03 框架理論 | 在同一事實下重新檢查問題定義、原因解釋、評價或處理方向，找出會改變選擇的另一種理解。 | 換框架不證明新因果真實；只換說法、沒有決策差別時無效。 |
| L04 爭點理論 | 尋找事實、定義、價值或行動上真實存在的競爭判斷，以及不同答案的現實後果。 | 不虛構反對者和爭議；事實未清時保持問句。 |
| L05 修辭情境 | 找此刻面臨具體選擇、可能因表達改變判斷的受眾，並檢查現實約束與時機。 | 沒有期限或行動視窗時不製造緊迫性。 |
| L06 自我參照效應 | 找原領域之外的人能聯絡自身的場景、損失、機會或選擇，寫清可檢驗的後果。 | 「大家都焦慮」不構成受眾連線；能聯想到自己不等於會點選。 |
| L07 社會認同與自我分類 | 檢查真實角色或群體的規範、身份、尊嚴與利益是否被素材觸及。 | 不靠刻板印象製造「我們／他們」；工具性素材可能沒有身份角度。 |
| L08 使用與滿足 | 問觀眾實際能拿內容來理解什麼、判斷什麼、嘗試什麼或與誰討論。 | 好奇與認同不能自動升級為實用價值；內容必須兌現該用途。 |
| L09 JTBD | 找行動主體在具體情境裡想推進的進展，以及原做法在哪一步受阻。 | 任務推斷不冒充當事人原話；有購買場景才分析購買進展。 |
| L10 情緒評價理論 | 分開檢查目標重要性、責任、確定性和可控制性，探索有條件的情緒與行動難題。 | 不憑理論診斷當事人的真實心理或聲稱方法能消除情緒。 |
| L11 認知失調 | 找可指出的舊判斷、行為或自我認識與材料中的相反經驗，研究判斷怎樣更新。 | 沒有可定位的矛盾時不使用「大家都以為」或反常識包裝。 |
| L12 沉默的螺旋 | 只在有意見氣候、孤立擔憂或表達代價線索時，檢查誰可能因此保持沉默。 | 「沒人說」不等於「不敢說」；缺證據時返回不適用。 |

## 給每組子 Agent 的簡報

每組收到同一份素材包，內容包括：原素材全文或可回溯摘錄、作者原命題、製作狀態與可改範圍、事實賬本（F 事實或作者主張、R 來源可信度、U 未知、H 假設）、原稿強句。簡報必須寫入以下約束，因為子 Agent 讀不到主 Skill：

- 本組負責的視角編號、判斷動作和邊界，只用這幾項；
- 主 Skill 的表達尺度：作者的強修辭、全稱判斷和口語概括預設保留，不因擴大受眾而建議削弱或加限定；
- 不寫標題、封面或口播，不編造經歷、資料、觀眾反應或動機；
- 不讀取其他組的輸出。

## 每組返回什麼

1. **逐視角一行**：視角編號，有效、待驗證還是不適用，一句話說明找到的路徑或缺了什麼條件。
2. **合併後的路徑，最多 2 條**：組內多個視角指向同一受眾和命題時合併成一條，註明來自哪些視角。每條寫清：
   - 上層命題、新增人群及其具體關切；
   - 原文錨點（引原句）→ 推導機制 → 新人群處境或後果；
   - 直接材料、合理推斷與待驗證假設；
   - 什麼事實會推翻這條路徑；
   - 當前製作狀態下：可直接兌現、需改稿、需補事實、需補拍，還是隻能另做一條；對應整條影片還是隻對應某一段。

找不到新增的真實受眾關係時，返回「本組未找到有效升層」並寫清原因，不為湊數編寫。

## 執行與完成

有子 Agent 能力時，3 組同時派出。建立 A、B、C 三項完成賬本；某組失敗時重試一次，仍失敗就如實標明缺席，不替它編寫結論。沒有子 Agent 能力時，主 Agent 依次完成三組，每組完成後再開始下一組，並告訴使用者這一次沒有獨立執行。

## 匯合與交付

三組返回後，主 Agent 按作者原意、獨特機制、受眾處境和爭點，把路徑匯成最多 3 個方向，並與快速掃描已有的方向去重。多個視角指向同一方向不提高它的優先順序。沒有材料支撐的結構問題、心理動機、因果和普遍結論只能列為待驗證。理論名用於溯源，不進入標題、封面或給使用者的預設說明。

匯合後執行 [材料選擇](material-selection.md) 的「內容價值驗收」，再按 [生產狀態與工作模式](production-state.md) 判斷每個方向的實現成本，交給 [候選比較](candidate-selection.md)。

面向使用者時按主 Skill 的預設交付格式輸出，深挖本身不改變格式。使用者說「展開」時，再給每組的逐視角結果和合並路徑。

角度選定後不再執行本流程。只有作者主張、關鍵事實或受眾任務發生實質變化，才重查受影響的組。
