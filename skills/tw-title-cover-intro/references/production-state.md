# 生產狀態與工作模式

文字標題、封面標題和影片開頭共享同一個內容入口，但最終發布形式與生產狀態會改變可以修改的範圍。先使用當前對話判斷；缺少的資訊會改變交付時必須追問。

檔案格式、材料標籤和輸入形態只能說明使用者提供了什麼。`#推文`、文章、Markdown、字幕或逐字稿等字樣不能證明使用者最終只發布文字，也不能證明影片尚未拍攝。最終用途和影片進度沒有明確說明時，在普通聊天訊息裡列出 1～5 項並讓使用者手動回覆數字；不呼叫彈框或表單工具，不聲稱已經彈出選項。

製作狀態與角度開發是兩條判斷線：先明確當前可修改範圍，再按主 Skill 選擇快速掃描或深挖；角度產生後用狀態篩選可兌現內容。深挖的各組先獨立提出命題，再判斷實現條件。只處理已拍影片的現有冷開場、未要求重做整條方向時，快捷路徑優先。不要按不同狀態增刪深挖的組，也不要把「當前不方便拍」等同於「沒有值得講的方向」。已確定角度或只改措辭時無需重新執行 12 視角。

## Mode 1：還在整理素材，稿子沒有形成

適用於只有素材、母題、事件、案例或模糊想法，稿件尚未形成、影片尚未拍攝的任務。

先挖掘值得講的事實、經歷、結果、衝突和受眾處境，再形成入口簡報。角度確定後寫清目標受眾、核心命題、可用錨點和最小補充材料；此時的文字標題、封面標題和開頭屬於生產假設，需要同時寫清正文必須提供的證據、過程或解釋。材料無法支援入口時，提出最小補充問題或建議暫緩生產。

## Mode 2：已經有稿子，影片還沒拍

適用於已有草稿或完整文稿，影片尚未拍攝、文章仍可修改的任務。

通讀內容，檢查選定角度最有價值的資訊是否真正進入正文。角度確定後，先交簡短角度簡報和必要的正文最小改動：哪些段落保留、前移、壓縮或補充，以及需要什麼事實或案例；再生成所需平台的文字標題、封面標題和可直介面播的開頭，附接入正文的下一句。發現標題需要正文沒有提供的資訊時，優先建議修改可改的稿件；使用者只允許改標題時收窄承諾。完整逐字稿只在使用者明確要求整稿改寫時交付。

## Mode 3：影片已經拍了，使用者還願意再拍一些內容

適用於影片已經拍過一版，使用者還願意重新拍幾句話、旁白、鏡頭或證明材料的任務。

先給出僅使用現有素材的可行版本，再列出採用更強角度時最值得重新拍攝的少量內容。新增口播、旁白、字幕大字和現有原話必須分別標記，讓使用者知道哪些內容需要重新制作。若補拍事實尚未提供，增強版標題只能標為暫定。

## Mode 4：影片已經拍完，不方便再拍

適用於無法再拍、無法復現場景、只能使用現有影片、字幕或逐字稿的任務。

從現有原話和畫面中選擇、前移、刪減和組合，兩種標題只能承諾成片能夠兌現的內容。角度掃描可能發現更廣的命題，但缺案例、解釋或畫面的方向應單列為未來內容，不與當前成片的可用主線混排。找不到足夠強的入口時，說明當前素材上限；不得用虛構成果、擴大因果或新寫引語填補缺口。

## Mode 5：從已錄好的較長內容中製作一條短影音

適用於課程、訪談、直播、會議或數十分鐘以上的連續素材，其中可能存在多個可獨立發布的內容。

先確定當前要剪出的一個具體切片或選題，再圍繞同一個切片做主 Skill 選定的角度分析；形成原話結構、回接方式和入口簡報，最後生成文字標題、封面標題與開頭。使用者已經給出明確切片時直接處理；不要讓不同成員從互不相干的片段各取一句，再拼出原素材沒有的連續論證。使用非連續片段時保留說話人、語義和聲畫連續性檢查。

## 矩陣批次生產：可以疊加在其他情況上

矩陣生產可以疊加在 Mode 2 至 Mode 5 上。方向確定後，按使用者要求批次生成不同平台、帳號或素材版本，並保持事實口徑穩定。批次版本需要有實際的資訊順序、受眾或展示條件差異，不能依靠近義改寫湊數量。

## 快捷路徑

下列請求可以直接處理：

- 使用者只改一句文字標題、封面標題或開頭，並已給出完整上下文；
- 使用者只要求從已拍素材中選擇或重排冷開場，沒有要求改變整條成片主線；
- 使用者已經鎖定方向，只要求壓縮字數、調整口語或適配平台欄位；
- 使用者已經明確最終用途時跳過用途提問；是否需要角度開發仍按主 Skill 路由，純文字本身不構成跳過角度開發的理由；
- 使用者明確要求沿用現有角度，不接受上游重做。

快捷路徑仍需遵守事實、兌現、素材來源和實際使用位置的限制。

## 怎樣向使用者確認情況

Mode 名稱只供 Skill 內部判斷。需要使用者補充資訊時，先用一兩句話說明為什麼要問，例如「同一段文字可以直接發，也可以拍成影片；拍沒拍、能不能補拍，決定我能改多少。」再在普通聊天訊息裡給出連續編號的 1～5 項（措辭見主 Skill），結尾寫「請直接回複數字」。選項本身已經說明各種情況，前面不再逐項展開解釋。使用者用文字說明時也應接受；不得要求使用者點選彈框。

第 5 項向使用者解釋時直接說「已經錄好一段較長的影片或音訊，準備從中選一部分做短影音」，不使用「長素材」「切片」「剪出一條」等製作術語。

使用者已經明確說明最終用途和製作進度時，直接進入對應處理方式，不重複解釋和追問。
