# 內容兌現檢查

推薦最終文案前讀取。按主 Skill 的「表達尺度」執行，檢查結果用於修正文案，無需給使用者展示整張清單。

同時執行 [寫作規則](writing-rules.md) 的獨立理解與自然措辭檢查。逐條隱藏正文和另一標題，確認當前文字本身交代了主題與必要關係；不得用分析說明替失敗成品補語境。字數檢查透過但讀者仍不知道在說什麼時，成品驗收失敗，先重寫再交付。

先問：這處表達會讓目標觀眾誤解哪項核心意思？修正帶來的理解收益是否值得新增的注意力成本？若只是能找到反例、可以更精確或少寫了次要條件，保留口語表達。只在影響主旨、關鍵事實或兌現時提出最小修改；不預設附帶嚴謹性診斷，也不把所有內部不確定性寫進成品。

1. **事實**：是否新增或篡改了數字、經歷、引語、身份和因果，是否把曝光寫成人數、個人結果寫成普遍保證？對作者原有的概數、經驗判斷和修辭強調結合語境判斷；只有承擔核心舉證或承諾的精確陳述才要求相應依據，不逐句索證。
2. **具體性**：是否保留這份材料的辨識度？換一篇同類內容也完全適用時，檢查是否遺漏具體事實或問題。
3. **繼續瞭解的理由**：觀眾能否預期後面還有什麼值得看？解釋型內容承諾的新增認識是否超過常識複述；故事、幽默和審美內容是否有值得繼續的過程或體驗。結論先行允許，空泛吊胃口應改寫。
4. **兌現**：正文是否真的給出承諾的結果、證據、過程、體驗或方法？不要求所有內容都改變觀眾的理解。沒有正文時標為暫定並指出需要補什麼。
5. **一致性**：本次同時提供的文字標題、封面標題和開頭是否指向同一內容？已確定的觀點與關鍵條件有沒有被改掉？
6. **分工**：文字標題、封面標題和開頭是否各自提供了有用資訊？方向一致不等於逐字重複；文字標題幫助觀眾識別與選擇，封面標題負責推薦流或主頁識別，開頭獨立建立觀看理由並推進內容。
7. **獨立性與銜接**：兩種標題在各自位置能否獨立辨識主題？開頭能否讓沒看標題的人進入當前事件、問題或體驗，下一句是否推進正文？
8. **素材來源**：新寫口播、原素材原話和 Agent 概括是否標記清楚？處理已拍素材時，不能把改寫句冒充成現有畫面裡的原話；沒有時間碼時不能編造精確切點。
9. **使用約束**：文字能否在實際位置讀懂，封面標題的換行與字數是否符合對應型別，口播能否自然念出，使用者指定的字數、時長和範圍是否滿足？
10. **角度與製作範圍**：標題和封面對應的是當前完整成片，還是隻對應其中一個片段？需要改稿或補拍的命題是否已明確標記，未拍版本的正文是否已安排兌現？同一成片範圍的候選才可並列比較。
11. **理論推斷**：快速掃描或深挖提出的新受眾、機制或公共問題是否仍標為推斷？理論名、路徑數量和共鳴猜測不能替代原文事實或實際結果；無有效路徑的視角不為湊數寫進承諾。

先修正影響核心理解的失真、無法兌現的承諾和來源錯誤，再比較表達力度。注意力成本與理解收益一起驗收；不以增加限定詞、補齊所有例外作為品質提升。不得為吸引注意補造事實；依賴缺失的核心事實才能成立的版本，不得混入可直接發布的推薦。
