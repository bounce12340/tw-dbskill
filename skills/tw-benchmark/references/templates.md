# 輸出模板與顆粒度對照表

本檔案在兩種情況下讀取：使用者要一份完整的對標分析報告；使用者已有對標、問怎麼模仿（路徑 D）。模板是上限，空的段落不寫。

## 2．單個對標的完整分析

```markdown
# 對標分析：{對標名稱}

## 對標物件評估
| 篩子 | 結果 | 依據 |
| --- | --- | --- |
| 1．賺錢 | ✅／❌／待核實 | {價格 × 估算銷量、團隊、投放等；估算標「推測」} |
| 2．看得懂 | ✅／❌ | {獲客：轉化：交付：復購主幹；看不懂的部分列為待拆解} |
| 3．能模仿 | ✅／❌ | {有無獨家渠道、資質、資金底線以上投入、已關閉的紅利；能力缺口單列} |

## 他的賺錢鏈條
- 獲客：{怎麼獲取客戶}
- 轉化：{怎麼讓人付錢}
- 交付：{怎麼交付產品}
- 復購：{怎麼讓人再買，含升單產品}

## 風險
- {紅利依賴、平台處罰、合規問題；沒有則省略}

## 模仿路徑
1. {第一步做什麼、對齊哪幾個維度}
2. {第二步}
3. {第三步}

## 你的判斷裡的噪音（僅在使用者的話裡出現時）
| 你的原話 | 屬於 | 處理 |
| --- | --- | --- |
| {引用} | 排除自我／討論本質 | {追問或改寫後的判斷} |

## 一句話
{一句直接的總結}
```

「對標物件評估」只評價對標本身。使用者的態度、興趣、顧慮只出現在「你的判斷裡的噪音」中。

## 3．顆粒度對照表

逐項對比使用者和對標。一致性只填三種：一致、不一致、待確認。

| 維度 | 對標 | 使用者 | 一致性 |
| --- | --- | --- | --- |
| 產品價格與價格梯度 | | | |
| 產品名稱與包裝 | | | |
| 獲客平台 | | | |
| 帳號主頁要素 | | | |
| 內容形式 | | | |
| 內容頻率 | | | |
| 標題與封面風格 | | | |
| 開頭結構、語速與鏡頭 | | | |
| 話術與文案調性 | | | |
| 自有社群引流與轉化話術 | | | |
| 交付方式 | | | |
| 促銷方式 | | | |

使用者已經在某個內容平台運營時，追加 `platform-operations.md` 中的平台運營維度。

處理規則：

1. 每一個不一致都要使用者給出理由。給不出理由，就改成和對標一致。
2. 理由屬於硬約束（法律、資質、健康與人身安全、資金底線）時，保留差異，並寫明它可能帶來的結果差距。
3. 理由屬於偏好、興趣、「我覺得這樣更好」時，歸為自我噪音，建議改回一致。
4. 對齊的是結構、要素和執行細節；對方的原創文稿、圖片、影片素材、商標與身份不直接複製。
5. 輸出時只列不一致項和待確認項，已經一致的維度合併成一句。
