# 使用者 個人設定（所有 tw-* skill 共用）

所有 skill 執行前先讀這份，再讀 `$MEDIA_TEAM/00-profile/voice.md`（以 voice.md 為準，兩者衝突時聽 voice.md）。

## 身分
- 作者專業背景：見本機 `shared/PROFILE.local.md`（不進版控）。
- 帳號：IG／Threads／X／YouTube Shorts／TikTok：（填入你的帳號）。主題：AI 創業、AI Agent 實戰、一人公司。
- 角度：每天和一群 AI Agent 一起工作的實際經驗。

## 寫作規則
- 台灣繁體中文、台灣用語：資料、運算資源、訓練資料、影片、品質、軟體、網路、領域、內捲、使用者、帳號、專案。
- 引號用「」，巢狀用『』。不用破折號（—、——）。
- 主張要有證據與出處連結；不捏造數字、引用、截圖。查不到就寫「無法查證」。
- 引述創作者的說法時中立標註：「某某說／某某表示」，不替對方加碼或扭曲。
- 每支影片圍繞它自己的賣點，不硬套 AI 治理角度。
- 油門／煞車比喻只能用在 AI agent 治理題目。
- 不攻擊 Anthropic。
- 背景素材不能有人臉、品牌標誌。每支影片都要有配樂與音樂署名。

## 平台規格（台灣常用）
| 平台 | 長度上限 | 習慣 |
|---|---|---|
| IG Reels | 說明 2,200 字；hashtag 最多 30，建議 3–5 個 | 直式 9:16，前 3 秒定生死，封面字要在中央安全區 |
| Threads | 每則 500 字；可串文 | 口語、像跟朋友講話，hashtag 只能 1 個主題標籤 |
| X | 加權 280（中文字算 2，約 140 中文字）；Premium 可長文 | 英文受眾多，可附英文版；引用原貼文優先 |
| YouTube Shorts | 標題 100 字元；3 分鐘內 | 標題放關鍵字，說明附出處與音樂署名 |
| TikTok | 說明 4,000 字元 | 由 使用者 本人發，只交檔案與說明 |
| LinkedIn | 3,000 字元 | 專業口吻，可中英雙語 |
| Facebook | 由 IG 同步為主 | 同步時顯示 IG 說明 |

## 團隊流程掛點
`01-leads`（情報蒐集角色）→ 選題（主控 bot）→ `03-drafts/<slug>/`（內容產製角色）→ `04-review/<slug>.md`（查核角色）→ 使用者確認 → `00-profile/publish-queue.md`（主控 bot 發布）→ `05-analytics/`（數據分析角色）。
所有 skill 只產出草稿與建議；發文、私訊、留言一律要 使用者確認。

## 各平台排序訊號（查證見 research/viral-patterns.md H5）
- IG Reels：觀看時間、每觸及按讚、每觸及分享（分享對非追蹤者最重要）。設計「想傳給朋友」的一句話。上傳無浮水印原檔。
- X：回覆、作者回覆留言者、停留時間、私訊分享。發完要回覆前幾則留言。連結放本文或回覆尚待測試。
- Threads：無官方說明，目前以回覆與分享為觀察指標（推論）。
- YouTube Shorts：觀看 vs 滑走、平均觀看時間、觀看百分比。前 1 秒就進主題。
- TikTok：互動、影片資訊（說明、音樂、hashtag），看完比例；粉絲數不是直接因素。
- LinkedIn：skip、長停留、留言、分享。前三行決定要不要點「更多」（推論）。
- 字幕：一律燒繁中字幕（靜音觀看比例無官方數字，但成本低）。
